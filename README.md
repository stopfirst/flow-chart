# 플로우 차트 (Flow Chart) · STOPFIRST

가격·ICT 레벨과 **프리미엄 · 거래소별 CVD · 합산 청산**을 한 장의 카드로 보는 웹앱입니다.
서버 없이 브라우저에서 각 거래소 공개 API를 직접 호출하며, 저장소에는 어떤 비밀값도 없습니다.

**바로 열기:** https://stopfirst.github.io/flow-chart/

- 주소 파라미터: `?s=BTC&tf=1h` · `?s=xyz:SP500&tf=4h` · `&bars=150` · `&mock=1`(모의 데이터 데모)
- **심볼 선택**: 툴바의 심볼 버튼(또는 PC에서 `/` 키) → 검색(티커·한글/영문 이름: `비트`, `금`, `나스닥`, `테슬라`…) + 탭(★즐겨찾기 / 최근 / 코인 / 주식·지수 / 원자재). 목록은 Hyperliquid 메인 무기한 + 모든 HIP-3 dex(xyz 등)에서 실시간으로 불러오며(10분 캐시) 가격 · 24h 변동률 · 24h 거래대금순. `BN`(Binance USDT 페어) · `CB`(Coinbase USD 현물) 배지는 해당 패널이 그려질 수 있다는 뜻입니다(24시간 캐시). 목록에 없는 심볼도 입력 후 Enter로 열 수 있습니다. 휴대폰에서는 아래에서 올라오는 시트, PC에서는 드롭다운(↑↓ · Enter · Esc).
- **즐겨찾기 칩**: 심볼 버튼 옆 가로 스크롤 칩으로 한 번에 전환. 목록의 ☆로 추가/삭제(기본: BTC · ETH · SOL · HYPE · xyz:SP500). 최근 8개 자동 기록.
- 없는 심볼을 열면 마지막 정상 차트를 유지하고 "종목을 찾지 못했어요: XXX"를 표시합니다.
- 휴대폰: 사이드 패널이 메인 차트 아래로 쌓입니다. 홈 화면에 추가하면 앱처럼 실행됩니다(PWA).
- **PNG 저장**: 화면 크기와 상관없이 항상 가로형(1600×860, 2배 해상도) 카드로 저장합니다. 휴대폰에서는 공유 시트가 열립니다.

## 화면 구성

| 영역 | 내용 | 데이터 |
|---|---|---|
| 헤더 | 심볼 · 타임프레임, 조회 시각(KST), 범례, 워터마크(설정에서 변경) | – |
| **가격·ICT** | 캔들(양봉 초록 / 음봉 분홍), EMA 20/50/100/200, 전일 고저(PDH/PDL, 회색 파선), 전일 MID(금색 굵은 실선), TDO(로즈색 얇은 실선 + 뉴욕 자정 세로 파선), 세션 박스(세션 시간대 위 연한 파선 사각형: 아시아 파랑 · 런던 초록 · 뉴욕 주황) + 세션 끝부터 오른쪽 끝까지 H/L 연장선, OB(얇은 실선 박스, 기본 백도식: 방향별 최근 1개, 라벨 `OB 2,386.0`), FVG(점선 박스), BB+FVG(브레이커+FVG 겹침, 연두/분홍 채움 + 진한 테두리 박스, 라벨 `BB+FVG 81,137`), 오른쪽 가격 라벨(예: `ASIA H 2,513.6`, 겹치면 펼치고 실제 레벨까지 지시선) | Binance 선물 → (실패 시) Binance 현물 → Hyperliquid |
| Coinbase 프리미엄 | `(Coinbase BTC-USD 종가 − Binance BTCUSDT 종가) / Binance × 100` (%) 막대. 양수 = 미국 현물 매수세 우위 | Coinbase Exchange 캔들, Binance 현물 |
| Binance 선물 CVD | 누적 `(테이커 매수 − 테이커 매도)` 거래대금(USDT) | fapi klines의 taker buy quote volume |
| Binance 현물 CVD | 위와 동일, 현물 | api/v3 klines |
| Coinbase 현물 CVD | 누적 `(매수 − 매도)` × 종가(USD) | Coinalyze `ohlcv-history`의 `bv`(매수량) |
| Hyperliquid 선물 CVD | 위와 동일 | Coinalyze `ohlcv-history` |
| 거래소 합산 청산 · 롱− / 숏+ | 롱 청산은 아래(분홍), 숏 청산은 위(초록) 막대, USD | Coinalyze `liquidation-history` (거래소별 무기한 최대 12개 합산) |

- EMA가 화면 가격 범위 밖에 있으면 범례에 `↑값` / `↓값`으로 표시합니다.
- CVD는 **화면 첫 봉부터 누적**합니다(절대값보다 기울기·다이버전스를 보세요).
- 데이터가 없는 패널은 숨깁니다. 예: `xyz:SP500`(Hyperliquid HIP-3)은 Binance·Coinbase가 없으므로 HL CVD(+Coinalyze에 있으면 청산)만 표시.
- 메인 차트/패널 위에 마우스를 올리거나 터치하면 같은 시점 값이 표시됩니다.

## 세션 정의 (ICT 킬존, 뉴욕 현지시간 · 서머타임 자동 반영)

| 세션 | 뉴욕(ET) | KST (EDT, 3~11월) | KST (EST, 11~3월) |
|---|---|---|---|
| 아시아 | 20:00–24:00 | 09:00–13:00 | 10:00–14:00 |
| 런던 | 02:00–05:00 | 15:00–18:00 | 16:00–19:00 |
| 뉴욕 | 07:00–10:00 | 20:00–23:00 | 21:00–24:00 |

- 각 세션의 **가장 최근 회차**를 표시합니다. 지금 세션이 진행 중이면 진행 중 회차(지금까지의 고가/저가, 라벨에 `(진행중)` / 휴대폰 `(진행)`), 아니면 가장 최근에 끝난 회차입니다.
- 경계는 끝 미포함 `[시작, 끝)` — 15분봉 기준 아시아(EDT)는 KST 09:00~12:45 시작 봉 16개.
- 세션 시간대 위에 연한 파선 박스를 그리고, 세션이 끝난 뒤 H/L을 오른쪽 끝까지 연장선으로 그립니다.
- 차트 헤더의 칩(**세션 / PDH·PDL / TDO / OB / FVG / BB+FVG**, PDH·PDL 칩은 전일 MID 포함)으로 레이어를 켜고 끌 수 있습니다(이 기기 localStorage에 저장, 기본 모두 켬, PNG 저장에도 반영).
- 4시간봉에서도 정확하도록 세션·전일 레벨은 항상 **15분봉**으로 계산합니다.
- **전일 고저(PDH/PDL)**: 직전 **UTC 일봉**(KST 09:00 ~ 다음날 09:00)의 고가/저가.
- **전일 MID (PD MID)**: `(PDH + PDL) / 2`. 오늘 UTC 일봉 시작(KST 09:00)부터 오른쪽 끝까지 금색 굵은 실선, 라벨 `PD MID 2,502.8` (휴대폰 `MID`).
- **TDO (True Day Open)**: 뉴욕 **00:00**(America/New_York, 서머타임 자동 반영)에 시작하는 봉의 시가. KST로 **EDT 기간 13:00 / EST 기간 14:00**(2026-11-01부터 EST). 지금이 오늘 뉴욕 자정 전이면 직전 자정 기준. 15분봉으로 계산하므로 4시간봉에서도 정확하며, 15분봉이 없을 때만 자정을 품은 봉의 시가를 쓰고 라벨을 `TDO≈`로 표시. 뉴욕 자정 봉에 연한 세로 파선 + 그 봉부터 오른쪽 끝까지 얇은 로즈색 실선.

## OB / FVG 규칙 (현재 타임프레임 기준, ATR = Wilder ATR 14)

**FVG (공정가치갭, 3봉)**
- 강세: `저가[i+1] > 고가[i−1]` → 구간 `[고가[i−1], 저가[i+1]]`
- 약세: `고가[i+1] < 저가[i−1]` → 구간 `[고가[i+1], 저가[i−1]]`
- 갭 크기 ≥ 0.1 × ATR 일 때만 인정
- 메움: 이후 가격이 갭 반대편 끝에 닿으면(강세: 저가 ≤ 하단, 약세: 고가 ≥ 상단) 그 봉에서 박스 종료
- 표시: 미충족 최근 4개(오른쪽 끝까지) + 화면 안에서 메워진 최근 3개

**OB (오더블록)** — ⚙ 설정의 **OB 방식**으로 선택 (기본 **백도식**, 이 기기 localStorage 저장)

*백도식 (기본, 구조 돌파 BOS/MSS 기준)*
- 스윙: 프랙탈(좌우 2봉). 고가가 왼쪽 2봉보다 높고 오른쪽 2봉 이상이면 스윙 고점(저점은 대칭). 오른쪽 2봉 마감 후 확정.
- 강세 OB: 어떤 봉의 **종가가 아직 돌파되지 않은 가장 최근 스윙 고점을 상향 돌파**(BOS)하면, 그 상승 레그(스윙 고점~돌파 봉 사이 최저가 봉이 원점)의 **상승 직전 마지막 음봉**(저가가 레그 하단 1/3 안) = OB.
- 변위 조건: `OB 봉부터 돌파 봉까지 최고가 − OB 저가 ≥ 1.5 × ATR` **또는** 그 사이에 강세 FVG가 있을 것.
- 구간 = 그 봉의 **몸통** `[min(시가,종가), max(시가,종가)]`. 몸통이 0.1 × ATR보다 작으면(도지) 바깥쪽 꼬리까지(강세는 저가까지) 넓힘.
- 약세 OB는 대칭: 스윙 저점 종가 하향 돌파 → 하락 직전 마지막 양봉의 몸통(도지는 고가까지).
- 한 스윙은 한 번만(BOS 1회 = OB 1개). 무효화: 돌파 이후 **종가**가 구간 반대편을 넘으면 삭제(강세: 종가 < 하단). 첫 터치는 기록만.
- 표시: 방향별로 **가장 최근 유효 OB 1개씩**(최대 강세 1 + 약세 1), 화면 가격 범위 안에 있을 때만. OB 봉부터 오른쪽 끝까지 얇은 박스 + 라벨 `OB 2,386.0`(구간 중앙가, 휴대폰은 `OB`).
- 참고: WhitePeach(백도) 차트를 보고 맞춘 근사 규칙입니다. 원본의 정확한 규칙은 공개되지 않았고, 무기한 선물 가격 기준이면 현물과 몇 달러 차이가 날 수 있습니다.

*넓게 (이전 방식)*
- 강세 OB: 음봉 j 다음 봉이 양봉이고, 이후 3봉 안에 **종가가 고가[j]를 돌파**하며, `최고가(j+1..j+3) − 저가[j] ≥ 1.5 × ATR` → 구간 `[저가[j], 고가[j]]`(꼬리 전체)
- 약세 OB: 양봉 j 다음 봉이 음봉이고, 3봉 안에 종가가 저가[j]를 하향 돌파하며, `고가[j] − 최저가(j+1..j+3) ≥ 1.5 × ATR`
- 무효화: 이후 **종가**가 구간을 반대로 이탈하면 삭제 (터치만으로는 유지)
- 표시: 현재가 위·아래 가까운 2개씩 + 현재가를 품은 1개, 오른쪽 끝까지 연장 + `OB` 라벨

**BB+FVG (브레이커 블록 + FVG 겹침, 일명 Unicorn)**
- 브레이커 블록 = **실패한 OB**. 위 **넓게(이전 방식)** OB 규칙으로 찾은 OB가(OB 방식 설정과 관계없이 항상 넓은 후보 사용 — 백도식은 BOS당 1개라 브레이커 후보가 너무 적음) 이후 **종가**로 반대편을 돌파당하면 방향이 뒤집혀 브레이커가 됩니다.
  - 약세 OB(하락 직전 양봉)를 종가가 **고가 위로** 돌파 → **강세 브레이커**
  - 강세 OB(상승 직전 음봉)를 종가가 **저가 아래로** 돌파 → **약세 브레이커**
- 브레이커 구간 = 그 OB 봉의 **몸통**(시가~종가). 바로 앞에 같은 색 봉이 이어지면 그 묶음(최대 3개) 몸통 전체.
- 돌파 변위 안의 **같은 방향 FVG**(가운데 봉이 OB 봉 이후이고, 돌파 봉 기준 −2 ~ +10봉 이내) 중 돌파에 가장 가까운 것 1개.
- **BB+FVG = 브레이커 구간 ∩ FVG 구간** — 겹치는 폭이 0보다 클 때만 표시(겹치지 않으면 없음).
- FVG 가운데 봉부터 오른쪽 끝까지 박스. 강세 = 연두 채움 + 진초록(#3f7f5f) 테두리, 약세 = 연분홍 채움 + 로즈(#b04a6a) 테두리. OB/FVG 박스 위에 그립니다.
- 무효화: FVG가 생긴 다음 봉부터 **종가**가 구간 반대편 끝을 넘으면(강세: 종가 < 하단, 약세: 종가 > 상단) 삭제. 꼬리 터치는 유지.
- 표시: 유효한 것 중 **현재가에 가까운 최대 2개**, 라벨 `BB+FVG 81,137`(구간 중앙가, 휴대폰은 `BB+FVG`). 칩 **BB+FVG**(기본 켬).
- 참고: 다른 도구(예: 무기한 선물 차트)와 가격·정의가 조금씩 달라 구간이 수십 달러 어긋날 수 있습니다.

규칙은 단순화한 버전입니다. 수치는 `js/calc.js`의 `findFVG`(minAtr) · `findOB`(mode 'baekdo'|'wide', swing, disp, doji) · `findBBFVG`(n, maxRun, wicks)에서 바꿀 수 있습니다.

## 설정 (⚙)

1. **Coinalyze API 키** (무료): https://coinalyze.net 가입 → https://coinalyze.net/account/api-key/ 에서 발급 → 설정에 붙여넣기.
   키는 **이 기기 브라우저(localStorage)에만** 저장되고 저장소/서버로 가지 않습니다.
   - 키가 없으면: Coinbase 현물·Hyperliquid CVD는 `캔들 방향 × 거래대금` **근사치**(제목에 "(근사)")로, 합산 청산은 숨김.
   - 한도: Coinalyze 무료 키는 **키당 분당 약 40회**입니다. 넘으면 HTTP 429(요청 한도 초과)가 납니다.
     - 새로고침 1회당 최대 **2회**만 호출: Coinbase 현물 + Hyperliquid CVD를 `ohlcv-history` 한 번에(심볼 콤마로 묶음), 청산 1회. 거래소 목록(3회)은 24시간 캐시.
     - 응답은 이 브라우저에 캐시: `max(60초, 봉 길이의 절반)` 안에는 다시 부르지 않고(15분봉 7.5분, 1시간봉 30분, 4시간봉 2시간), 그 뒤에는 **마지막 봉 − 2봉부터만** 받아 이어 붙입니다. 캐시가 있으면 패널을 바로 보여주고 뒤에서 갱신합니다.
     - 탭·창이 여러 개여도 같은 브라우저에서는 **분당 30회**로 함께 제한(순차 호출).
     - 429가 오면 `Retry-After`(초, 없으면 10초)를 읽어 15초 이하면 기다렸다가 1번만 재시도, 더 길면 그 시간 동안 Coinalyze 호출을 쉬고 캐시 데이터를 회색 안내("Coinalyze 한도 대기 중 · 캐시 데이터 표시 (n초 후 재시도)")와 함께 표시합니다. 캐시가 전혀 없을 때만 ⚠ 경고가 뜹니다.
     - 같은 키를 다른 기기(폰·PC)에서 동시에 쓰면 한도를 나눠 씁니다(기기 간 제한은 공유되지 않음) → 자동 새로고침은 **1분 이상**, 여러 기기면 더 길게 권장.
2. **Coinalyze 프록시 URL** (선택): 브라우저에서 Coinalyze 직접 호출이 CORS로 막힐 때만. `proxy/coinalyze-proxy.js`를 서버(예: Lightsail)에 띄우고 `https://내서버/v1` 입력.
3. **워터마크 라벨**: 카드 오른쪽 위 문구(기본 `STOPFIRST`).
4. **OB 방식**: `백도식`(기본, BOS 직전 마지막 반대색 봉 몸통, 방향별 1개) / `넓게`(이전 방식, 꼬리 전체, 여러 개).

## 참고 · 한계

- Binance는 미국 등 일부 지역 IP를 차단(HTTP 451)합니다. 한국에서는 정상 동작합니다. 선물이 막히면 가격은 현물로 대체되고 선물 CVD 패널은 숨겨집니다.
- 프리미엄은 USD(Coinbase) 대 USDT(Binance) 비교라 USDT 디페그만큼의 상시 오프셋이 있습니다.
- Coinalyze 장중 데이터는 약 1500~2000개 포인트만 보관합니다.
- 모든 시각은 KST(UTC+9)로 표시합니다. 날짜 형식은 `월/일, 시:분`.
